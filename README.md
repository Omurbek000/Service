# Service
Общая схема пайплайна Пользователь загружает видео → Django REST принимает файл, сохраняет, в свою очередь ставит задачу Извлечение аудио из видео (ffmpeg) Определение языка + распознавание речи (ASR) — Whisper делает это одновременно Показываем клиенту: «Общий язык: английский» → предлагаем выбор: субтитры или дубляж. Если субтитры → генерация .srt/.vtt, наложение на видео Если дубляж → перевод текста → синтез речи (TTS, например CosyVoice) → синхронизация по таймингам → замена/микс аудиодорожки → сборка видео
